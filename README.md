# Restore Vitality Health: website

The finished static website, English at the root and Spanish under `es/`, 76 pages in all.

## What's here
- `dist/`: the public website only, ready to deploy. Every page (English and `es/`), `assets/`, `robots.txt` and
  `sitemap.xml`. Generated by `site/tools/publish.py`; don't edit it by hand.
- `site/`: the working copy. The same built pages plus everything used to make them (below).
- `site/src/`: the page sources (partials, page bodies, templates). Edit these, not the built `.html` files.
- `site/data/`: products, site strings and the photo list the pages are built from.
- `site/tools/`: `build.py` rebuilds every page from the sources; `check.py` and `qa.py` check the result.
- `content/`: the copy decks (FAQ answers are read from here word for word).
- `assets/legal/`: the client's legal text, used verbatim for the legal pages.

## Change something
```
cd site
python tools/build.py     # rebuild all 76 pages from src/, data/ and content/
python tools/check.py     # 0 errors expected
python -m http.server 8740 --bind 127.0.0.1    # preview at http://127.0.0.1:8740/
python tools/qa.py index.html es/index.html --base http://127.0.0.1:8740/   # browser checks (needs Playwright)
```
Needs Python 3 with Jinja2 and MarkupSafe.

## Deploy a preview (Netlify)
```
cd site
python tools/build.py && python tools/check.py
python tools/publish.py   # refreshes ../dist with only the public files
```
Then deploy the `dist` folder: drag it onto Netlify Drop, or `netlify deploy --dir=dist` from this folder for a draft
link (leave out `--prod` for a client preview). Never deploy `site/`: it also holds the page sources and tools.
Preview links are unlisted, not private: anyone with the link can open them.
